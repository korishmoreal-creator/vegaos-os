# vegaos-opensource (vegaos-os)
An open source release of VegaOS for security research/development.

Proprietary services that hook to NyaNet are either removed or skipped over.

Generally, AM/BM testing for UI elements are removed. (In betas, AM is used.)

In specific, proprietary elements that are excluded are included in release description.

Release descriptions will mirror the descriptions on the website/Web OSes JBs server.

Legacy/Offline UI may be used as a fallback in contrast to vegaos-propri

Happy coding!
